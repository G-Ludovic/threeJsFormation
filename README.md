# Mini Projet Three.js (Projet d’apprentissage)

##  Description
Un mini-projet d’initiation à **three.js**, la bibliothèque JavaScript pour créer des scènes 3D dans le navigateur Web via WebGL.  
Cette application met en place une scène simple qui est un cube tournant.

##  Ressources utiles
- Documentation officielle : [three.js](https://threejs.org),
- Tuto YouTube de "Chicken Code School" : [Chicken Code School](https://youtu.be/_hdB8-LaQXw?list=PLV6sQ8q0YXgm1OjmCw5yg-2KItufx4Z8a),
- Bibliothèque JavaScript 3D utilisée : [NPM three.js](https://www.npmjs.com/package/three).

##  Prérequis
- Avoir des bases en **JavaScript** (ES6+ recommandé)  
- Connaître le **HTML/CSS**  
- Navigateur moderne compatible **WebGL**
